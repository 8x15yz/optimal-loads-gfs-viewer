1. 데이터 특성

예보 데이터는 모델 실행 시각(run time)과 예보 간격(step)을 기준으로 정의됩니다. 실제 예보 시각(valid time)은 실행 시각에 step 시간을 더해서 계산합니다.

예시: run_time_utc=2026-02-02T06:00:00Z, step_hours=24는 2026-02-03 06:00 UTC 예보값을 의미합니다.

2. 데이터 출처

ECMWF IFS

대기 및 파랑 예보 데이터입니다. API 매핑은 source=ecmwf, model=ifs입니다.

NOAA GFS

대기 및 파랑 예보 데이터입니다. API 매핑은 source=noaa, model=gfs입니다.

3. 데이터 가용성

두 출처 모두 하루 네 번 실행됩니다: 00Z, 06Z, 12Z, 18Z.

SourceStep intervalMaximum range
ECMWF IFS144h까지 3시간 간격, 이후 확장 run은 6시간 간격최대 360h
NOAA GFS384h까지 3시간 간격최대 384h

6. API 사용법

EndpointDescription
GET /api/griddata격자형 변수 데이터를 조회합니다.
GET /api/gridfile원본 GRIB2 단일 파일의 임시 URL을 반환합니다.
GET /api/sources사용 가능한 데이터 출처 목록을 반환합니다.

GET /api/griddata
  ?source=noaa
  &dataset_code=original
  &model=gfs
  &variable=HTSGW
  &run_time_utc=2026-02-02T06:00:00Z
  &step_hours=24
  &lat=35.0&lon=129.0&buffer_km=200

7. 결과 배열 읽기

값은 row-major, bottom-up 순서로 저장됩니다. values[0]은 남서쪽 격자 셀입니다.

index = y * nx + x
x: west to east
y: south to north

8. 풍속/풍향 공식

wind_speed = np.hypot(u, v)
wind_dir_from = (270.0 - np.degrees(np.arctan2(v, u))) % 360.0

풍향은 기상학적 FROM-direction 규칙을 사용합니다. 0°는 북쪽이며 시계방향으로 증가합니다.

9. 빠른 시작

GET /api/latest 한 번만 호출하면 — 파라미터 없이 — 현재 시점 기준 NOAA GFS Wave 7개 변수(최대 89 step)와 당일 EOT20 천문조위(8 step) 전체의 presigned 다운로드 URL을 담은 매니페스트 JSON을 받을 수 있습니다.

1회성 스냅샷: 매니페스트에 포함된 모든 presigned URL은 issued.expires_at(요청 시점으로부터 1시간 후)에 만료됩니다. 새 데이터가 필요하면 /api/latest를 다시 호출하세요.

엔드포인트

GET http://weather-api.bmap.kr/api/latest

다운로드 스크립트 사용법

# 전체 다운로드 (/api/latest 자동 호출)
python download_latest.py

# 매니페스트 저장 후 다운로드
python download_latest.py --save-json latest.json

# 저장된 매니페스트로 다운 (API 재호출 없이, 1시간 이내)
python download_latest.py --from-json latest.json

# 특정 변수만 선택
python download_latest.py --vars HTSGW WIND tidal_elevation

# 동시 다운로드 수 및 저장 경로 지정
python download_latest.py --workers 16 --out-dir ./data
